A momentum paper-trading bot for pump.fun bonding curves: it buys only mature curves (50+ trades, 25+ SOL raised) with accelerating net buy flow — buy volume at least 4x sell volume across the last 20 trades, from 10+ distinct buyers, with price up 35% over the window and within 5% of its high — sizes every position at a flat 0.15 SOL with no pyramiding, and exits first each batch on stop-loss, trailing stop, take-profit, fade, big-seller, or max-hold signals. Deterministic: no clock, no environment, no randomness.
## Run it
```sh
node main.ts
```
